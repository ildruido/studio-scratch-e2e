# Branch: success metrics

Builds on: the product foundation and the personas (the primary persona above all). If the MVP exists, read it too.

## Outline

- **The main metric:** the one number that shows users are getting the product's value.
- **Three to five supporting metrics.**
- **Early signals for the MVP:** what can be seen in the first weeks, before the main metric can move.
- **Guardrails:** what must not get worse while the main metric improves (cost per user, trust, quality).
- **Assumptions** and **Open questions.**

Every metric has a definition precise enough for two people to count the same number, a target, when it is checked, and how it is measured.

## Rules this document adds

- A metric nobody could measure with what the MVP will have is rewritten or dropped. Ask "where would this number come from?" for each.
- Prefer what users do over what they say, and value received over activity (a count of sign-ups is not value).
- A target without evidence is an assumption: label it, and say which study or test would set it properly.
- The main metric is a product decision: ask it as a question with your recommended answer, and record the decision.
